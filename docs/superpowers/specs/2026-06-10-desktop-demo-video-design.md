# Windows Desktop Demo Video Design

## Goal

Create a polished software demo video for the Windows desktop version of the perpetual calendar app. The video is meant for friends or customers, so it should feel clear, credible, and practical instead of overly promotional.

## Output

- Runtime: about 75-90 seconds.
- Format: landscape desktop video, preferably 1920x1080 at 30 fps.
- Audio: no voiceover. Use screen recording, optional light background music, and on-screen captions.
- Style: real product operation with simple title cards, subtle zooms, highlight boxes, and concise Chinese captions.

## Storyboard

1. Opening, 0-5 seconds
   - Show title: "万年历桌面应用".
   - Show subtitle: "公历、农历、节气、纪念日与日记，一站式管理".

2. Calendar overview, 5-18 seconds
   - Open the Windows desktop app.
   - Show the full month calendar, current day highlight, and month switching.
   - Caption: "清晰月视图，快速查看每一天".

3. Daily information, 18-32 seconds
   - Click a date.
   - Show lunar date, ganzhi, zodiac, festival, and solar term details.
   - Caption: "公历农历、干支生肖、节气节日自动呈现".

4. Monthly events and seasonal recommendations, 32-45 seconds
   - Scroll the right-side detail panel.
   - Show monthly events and seasonal recommendation cards.
   - Caption: "节日安排与当季生活建议，一眼掌握".

5. Anniversaries, 45-58 seconds
   - Add a sample anniversary.
   - Show solar/lunar type selection and the saved list item.
   - Caption: "重要日子不再错过，支持阳历与阴历纪念日".

6. Diary, 58-76 seconds
   - Open the floating diary page.
   - Show new diary creation, rich text editing, attachment area, and all diary list.
   - Caption: "把每天的心情、事件和文件都记录下来".

7. Closing, 76-88 seconds
   - Return to the main calendar view.
   - Show final caption: "日历、提醒、纪念日、日记，一屏相连".
   - End card: "万年历桌面应用".

## Production Plan

- Run the desktop app locally and capture real interactions.
- Keep test data simple and non-sensitive: one anniversary and one short diary entry.
- Use large, readable captions with a calm desktop-app style.
- Add highlight boxes or zooms only where they help the viewer notice the feature.
- Export a preview first, review it for readability and pacing, then render the final MP4.

## Verification

- The video shows all requested functions: calendar, daily info, monthly events, seasonal recommendations, anniversaries, and diary.
- Captions are readable at normal viewing size.
- No private or accidental local data appears in the recording.
- The final video duration is within the planned 75-90 second range unless pacing requires a small adjustment.
